# Roadmap recomendado

## Fase 1 — Readiness GRC
- Perfil de organización
- Aplicabilidad preliminar
- Assessment
- Evidence readiness
- GAP analysis
- Plan de acción
- Exportación `ens-project.json`

## Fase 2 — Gestión
- Inventario de evidencias
- Historial de cambios
- Estado de acciones
- Riesgos y matriz
- Exportación PDF dedicada

## Fase 3 — Integración
- Importación/exportación con Compliance Studio
- Mapeos revisados de controles
- Versionado del marco
- Trazabilidad control → evidencia → gap → acción

## Fase 4 — Plataforma
Solo cuando el modelo GRC esté estabilizado:
- backend
- usuarios/roles
- persistencia centralizada
- API
- integraciones externas
