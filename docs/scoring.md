# Scoring

Sí = 1; Parcialmente = 0,5; No/No sé = 0; No aplica se excluye del denominador.

`Readiness = puntos obtenidos / controles evaluables * 100`.

Evidence readiness: Ninguna = 0; Parcial = 0,5; Suficiente = 1.

Los indicadores sirven para priorizar trabajo GRC y no deben presentarse como certificación o porcentaje oficial de adecuación ENS.
