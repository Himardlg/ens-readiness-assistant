# Modelo de evidencia

Cada control registra:
- evidencia esperada (catálogo);
- disponibilidad de evidencia (Ninguna / Parcial / Suficiente);
- responsable, fecha objetivo, estado de la acción (pendiente / en curso / hecho) y esfuerzo (S/M/L);
- observaciones.

El informe distingue «declarado» de «verificable» y marca los controles con «Sí» sin evidencia.

Evolución prevista: identificadores únicos de evidencias, fuente, fecha, propietario, periodo de validez y relación con hallazgos.
