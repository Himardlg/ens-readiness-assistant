# Guía de uso

1. Completa el perfil de organización.
2. Responde el bloque de aplicabilidad y contexto.
3. Para cada control selecciona el estado real.
4. No utilices "Sí" si no puedes demostrar razonablemente el control.
5. Registra la evidencia disponible.
6. Añade responsable y fecha cuando exista un gap.
7. Genera el assessment.
8. Revisa el plan de acción.
9. Guarda la evaluación localmente o exporta `ens-project.json`.

## Interpretación

El Readiness % sirve para comparar el estado interno de la evaluación entre iteraciones. No debe presentarse como "X% de cumplimiento ENS".

El Evidence Readiness mide la preparación documental/evidencial declarada en la herramienta.
