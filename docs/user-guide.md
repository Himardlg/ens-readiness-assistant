# Guía de uso

1. Completa el perfil de organización (nombre y tipo obligatorios).
2. Responde el bloque de aplicabilidad y contexto (impactos y tipos de información).
3. En el assessment, usa los filtros (área, prioridad, sin responder) y responde cada control.
4. No utilices «Sí» si no puedes demostrarlo; registra la evidencia disponible.
5. Añade responsable, fecha, estado y esfuerzo de la acción cuando exista un gap.
6. Genera el assessment y revisa el plan de acción.
7. Exporta el plan a **CSV** (Excel) o el proyecto a `ens-project.json`; imprime/PDF desde el navegador.

## Guardado
- La herramienta **autoguarda** en este navegador. Al volver, ofrece recuperar o descartar el borrador.
- «Guardar» fuerza el guardado y «Cargar» recupera la última versión.
- Para compartir o archivar, usa **Exportar JSON** e **Importar JSON** (los ficheros se validan al importar).

## Interpretación
- **Readiness declarado**: lo que afirmas, ponderado por prioridad.
- **Readiness verificable**: lo que además puedes demostrar con evidencia.
- **Evidence readiness**: preparación documental declarada.

Sirven para comparar iteraciones; no deben presentarse como «X% de cumplimiento ENS».
